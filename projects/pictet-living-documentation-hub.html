Pictet Tech – Living Documentation Hub

2026-Q3

Why

To close the gap between intended documentation in Wiki and the actual running solution deployed on the cluster.

What

The Living Documentation Hub is a central web portal for all technical documentation, which content reflects what is currently implemented and ensures that information is always up-to-date and easily accessible to developers and stakeholders like Solution Architects, Quality Assurance, Business Analysts, Product Owners, and Project Managers. This tool must support the Product vision.
